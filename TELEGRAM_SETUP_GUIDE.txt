================================================================
Telegram告警配置快速指南
================================================================

🔔 为爆仓金额监控配置Telegram通知

================================================================
一、创建Telegram Bot
================================================================

1️⃣ 打开Telegram，搜索 @BotFather

2️⃣ 发送命令创建bot:
   /newbot

3️⃣ 按提示设置:
   - Bot名称: Liquidation Alert Bot (或任意名称)
   - Bot用户名: liquidation_alert_bot (必须以_bot结尾)

4️⃣ 获取Bot Token:
   创建成功后，BotFather会返回类似这样的token:
   ```
   123456789:ABCdefGHIjklMNOpqrsTUVwxyz-1234567890
   ```
   ⚠️ 保存这个token，后面需要用到

================================================================
二、获取Chat ID
================================================================

方法1: 个人聊天
------------------
1️⃣ 搜索 @userinfobot
2️⃣ 点击Start
3️⃣ 发送任意消息
4️⃣ Bot会返回你的信息，包含chat_id:
   ```
   Id: 123456789
   ```

方法2: 群组聊天
------------------
1️⃣ 创建一个Telegram群组
2️⃣ 将你的bot添加到群组
3️⃣ 在群组中发送一条消息 @your_bot_name
4️⃣ 访问以下URL获取chat_id:
   ```
   https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getUpdates
   ```
5️⃣ 在返回的JSON中查找 "chat":{"id":-123456789,...}
   群组的chat_id通常是负数

================================================================
三、创建配置文件
================================================================

1️⃣ 创建configs目录（如果不存在）:
   ```bash
   cd /home/user/webapp
   mkdir -p configs
   ```

2️⃣ 创建telegram_config.json文件:
   ```bash
   nano configs/telegram_config.json
   ```

3️⃣ 填入配置内容:
   ```json
   {
     "bot_token": "123456789:ABCdefGHIjklMNOpqrsTUVwxyz-1234567890",
     "chat_id": "123456789"
   }
   ```
   
   替换为你自己的:
   - bot_token: 从BotFather获取的token
   - chat_id: 从userinfobot获取的chat_id

4️⃣ 保存并退出:
   - 按 Ctrl+O 保存
   - 按 Ctrl+X 退出

================================================================
四、测试配置
================================================================

1️⃣ 测试脚本:
   ```bash
   cd /home/user/webapp
   python3 << 'EOF'
   import json
   import requests
   
   # 读取配置
   config = json.load(open('configs/telegram_config.json'))
   bot_token = config['bot_token']
   chat_id = config['chat_id']
   
   # 发送测试消息
   url = f"https://api.telegram.org/bot{bot_token}/sendMessage"
   data = {
       'chat_id': chat_id,
       'text': '🔔 Telegram配置测试成功！\n爆仓金额监控已启用。',
       'parse_mode': 'Markdown'
   }
   
   response = requests.post(url, data=data)
   result = response.json()
   
   if result.get('ok'):
       print("✅ 测试消息发送成功！")
       print("请检查Telegram是否收到消息")
   else:
       print("❌ 发送失败:")
       print(result)
   EOF
   ```

2️⃣ 检查Telegram:
   - 你应该会收到一条测试消息
   - 如果没收到，检查bot_token和chat_id是否正确

================================================================

1️⃣ 使用PM2启动（推荐）:

   ```bash
   pm2 logs liquidation-alert-monitor --lines 50
   ```

4️⃣ 停止服务:
   ```bash
   pm2 stop liquidation-alert-monitor
   ```

5️⃣ 重启服务:
   ```bash
   pm2 restart liquidation-alert-monitor
   ```

八、常见问题
================================================================

❌ 问题1: "Unauthorized" 错误
解决: bot_token不正确，检查是否从BotFather复制完整

❌ 问题2: "Chat not found" 错误
解决: chat_id不正确，或bot还未与用户/群组建立会话
     解决方法: 在Telegram中给bot发送 /start 命令

❌ 问题3: 群组中bot不回复
解决: 
1. 确保bot是群组成员
2. 确保bot有发送消息的权限
3. chat_id使用负数（群组）

❌ 问题4: 配置文件格式错误
解决: 
```bash
# 验证JSON格式
python3 -m json.tool configs/telegram_config.json
```

九、安全建议
================================================================

🔒 保护你的配置:
1. 不要将telegram_config.json提交到Git
2. 设置文件权限: chmod 600 configs/telegram_config.json
3. 定期更新bot_token（通过@BotFather）
4. 不要在公开场合分享bot_token
