🔧 技术实现细节
────────────────────────────────────────────────────────────────────────────

ECharts markPoint 配置:
  {
    symbol: 'pin',                    // 图钉形状
    symbolSize: 50,                   // 标记大小
    label: {
      show: true,
      formatter: '24H最大\n{value}万', // 标签文字
      color: '#fff',                   // 白色文字
      fontSize: 11,
      fontWeight: 'bold'
    },
    itemStyle: {
      color: '#ef4444'                 // 红色图钉
    },
    data: [{
      coord: [maxIndex, maxAmount],    // 坐标位置
      value: maxAmount.toFixed(2),
      name: '24小时内1H爆仓最大值'
    }]
  }
