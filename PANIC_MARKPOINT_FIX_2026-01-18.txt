二、问题根因分析
----------------------------------------------------------------------------------------

经过深入调查，发现代码存在**严重的逻辑错误**：

❌ 原始代码逻辑：
```javascript
// 错误：使用1小时爆仓金额计算"24小时最大值"
const amounts = pageData.map(d => d.hour_1_amount);

// 计算24小时最大值（实际上是1小时爆仓的最大值）
const max24hAmount = Math.max(...amounts);
const max24hIndex = amounts.indexOf(max24hAmount);
```

问题点：
1. **变量名误导**：`max24hAmount` 实际上存的是 `hour_1_amount` 的最大值
2. **数据来源错误**：应该使用 `hour_24_amount` 字段，而不是 `hour_1_amount`
3. **用户需求未满足**：用户要求标记"24小时爆仓金额的最大值"

数据结构说明：
- `hour_1_amount`: 1小时内的爆仓金额（曲线展示的数据）
- `hour_24_amount`: 24小时内的爆仓金额（应该用来找最大值）


三、修复方案
----------------------------------------------------------------------------------------

✅ 修复后的代码逻辑：

1. **正确提取数据**：
```javascript
// 1小时爆仓金额数据（用于绘制曲线）
const amounts = pageData.map(d => d.hour_1_amount);

// 24小时爆仓金额数据（用于找最大值）
const amounts24h = pageData.map(d => d.hour_24_amount);
```

2. **正确计算最大值**：
```javascript
// 计算24小时爆仓金额的最大值（这才是我们要标记的）
const max24hAmount = Math.max(...amounts24h);
const max24hIndex = amounts24h.indexOf(max24hAmount);
const max24hTime = times[max24hIndex];
```

3. **增强控制台输出**：
```javascript
console.log('📊 图表数据:', {
    dataPoints: amounts.length,
    '1H爆仓平均值': avgAmount,
    '24H爆仓最大值': max24hAmount,
    '24H最大值索引': max24hIndex,
    '24H最大值时间': max24hTime
});
```

4. **改进Tooltip显示**：
```javascript
formatter: function(params) {
    const currentIndex = p.dataIndex;
    const is24hMax = currentIndex === max24hIndex;  // 检查是否是24H最大值位置
    const amount24h = amounts24h[currentIndex];      // 获取该点的24小时爆仓金额
    
    return `<div style="padding: 8px;">
        💥 1H爆仓: ${amount} 万美元
        📊 24H爆仓: ${amount24h.toFixed(2)} 万美元${is24hMax ? ' 🔥' : ''}
        ${is24hMax ? '🔥 24小时爆仓最大值！' : ''}

}
```

八、技术要点
----------------------------------------------------------------------------------------

数据分离原则：
  ✓ 曲线数据：使用 hour_1_amount（1小时爆仓）
  ✓ 标记数据：使用 hour_24_amount（24小时爆仓）
  ✓ 平均值计算：基于曲线数据（hour_1_amount）
  ✓ 最大值查找：基于24小时数据（hour_24_amount）

ECharts配置关键点：
  - markPoint.data[0].coord = [max24hIndex, max24hAmount]
    ↑ 坐标必须使用24小时数据的索引和数值

  - series[0].data = amounts（1小时爆仓数据）
    ↑ 曲线使用1小时数据绘制

  - 关键：两个数组长度相同，索引对应相同的时间点

闭包变量：
  - amounts24h 必须在 formatter 函数外定义
  - 这样 tooltip 的 formatter 才能访问到每个点的24H数据


九、为什么之前看不到标记？
----------------------------------------------------------------------------------------

可能的原因：

1. ❌ **数据匹配失败**（最主要原因）
   - 用1小时爆仓的最大值（588.47万）去查找坐标
   - 但实际要标记的是24小时爆仓的最大值
   - 坐标计算错误导致标记位置不正确或超出范围

2. ❌ **索引不匹配**
   - max24hIndex 是基于 amounts（1小时数据）计算的
   - 如果1小时最大值和24小时最大值不在同一位置
   - 标记就会打在错误的点上

3. ❌ **变量名误导**
   - 代码写着 "max24hAmount"，但实际是1小时数据
   - 维护时容易产生混淆

4. ✅ **浏览器缓存**（次要原因）
   - 即使修复了，浏览器缓存也可能导致看不到更新
   - 需要强制刷新（Ctrl+Shift+R）
