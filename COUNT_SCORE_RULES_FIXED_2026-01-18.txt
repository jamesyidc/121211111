一、规则说明
======================================================================

计次得分根据 **时间段** 和 **count值** 计算星级得分。
规则分为 4 个时间段，每个时间段有不同的阈值。

实心星（★）= 越少越好（计次少）
空心星（☆）= 计次偏多（不理想）

======================================================================
二、完整规则表
======================================================================

【截止6点前】（0:00 ~ 5:59）
  实心星：
    - count ≤ 1              → ★★★ (实心3星)
    - 1 < count ≤ 2          → ★★  (实心2星)
    - 2 < count ≤ 3          → ★   (实心1星)
  空心星：
    - 3 < count ≤ 4          → ☆   (空心1星)
    - 4 < count ≤ 5          → ☆☆  (空心2星)
    - count > 5              → ☆☆☆ (空心3星)

【截止12点前】（6:00 ~ 11:59）
  实心星：
    - count ≤ 2              → ★★★ (实心3星)
    - 2 < count ≤ 3          → ★★  (实心2星)
    - 3 < count ≤ 4          → ★   (实心1星)
  空心星：
    - 4 < count ≤ 5          → (无评级)
    - 5 < count ≤ 6          → ☆   (空心1星)
    - 6 < count ≤ 7          → ☆☆  (空心2星)
    - count > 7              → ☆☆☆ (空心3星)

【截止18点前】（12:00 ~ 17:59）
  实心星：
    - count ≤ 3              → ★★★ (实心3星)
    - 3 < count ≤ 4          → ★★  (实心2星)
    - 4 < count ≤ 5          → ★   (实心1星)
  空心星：
    - 5 < count ≤ 7          → (无评级)
    - 7 < count ≤ 8          → ☆   (空心1星)
    - 8 < count ≤ 9          → ☆☆  (空心2星)
    - count > 9              → ☆☆☆ (空心3星)

【截止24点前】（18:00 ~ 23:59）
  实心星：
    - count ≤ 4              → ★★★ (实心3星)
    - 4 < count ≤ 5          → ★★  (实心2星)
    - 5 < count ≤ 6          → ★   (实心1星)
  空心星：
    - 6 < count ≤ 9          → (无评级)
    - 9 < count ≤ 10         → ☆   (空心1星)
    - 10 < count ≤ 12        → ☆☆  (空心2星，推断)
    - count > 12             → ☆☆☆ (空心3星，推断)

四、规则逻辑说明
======================================================================

1. **随时间递增**：
   - 越晚的时间段，容许的 count 值越大
   - 6点前 count≤1 是3星，12点前需要 count≤2，18点前需要 count≤3，24点前需要 count≤4

2. **中性区域**：
   - 存在部分 count 值没有明确的星级定义（显示为空或"--"）
   - 这些区域介于实心星和空心星之间，表示"一般"状态

3. **空心星阈值差异**：
   - 6点前：空心1星从 count>3 开始
   - 12点前：空心1星从 count>5 开始
   - 18点前：空心1星从 count>7 开始
   - 24点前：空心1星从 count>9 开始
