三、可能原因分析
================================================================

原因1: 浏览器缓存 ⭐⭐⭐⭐⭐
------------------
最可能的原因！

现象:
- 代码已更新但浏览器仍使用旧版本
- 页面标题仍显示 v2.1（应该是 v2.2）

解决方案:
1. 强制刷新: Ctrl + F5 (Windows) 或 Cmd + Shift + R (Mac)
2. 清除缓存:
   - Chrome: F12 → Network → Disable cache (勾选)
   - 或右键刷新按钮 → 清空缓存并硬性重新加载
3. 无痕模式:
   - Ctrl + Shift + N (Chrome)
   - 在无痕窗口打开页面

原因2: 数据量问题 ⭐⭐⭐
------------------
如果当前页面只有少量数据点。

现象:
- 数据点太少，markPoint可能不明显
- 或者最大值在边缘位置

检查方法:
- 打开浏览器控制台 (F12)
- 查看 "📊 图表数据" 日志输出
- 确认 dataPoints 数量和 max 值

原因3: echarts版本问题 ⭐⭐
------------------
markPoint在某些版本可能有bug。

当前使用版本: echarts@5.4.3

解决方案:
- 已使用稳定版本，应该没问题

原因4: 图表初始化时机 ⭐
------------------
如果在数据加载完成前初始化。

当前代码:
- 数据加载后才设置option
- 应该没有时序问题
