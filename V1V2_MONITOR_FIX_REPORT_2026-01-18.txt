四、系统功能
================================================================

📊 V1V2成交额监控系统功能:

1. 实时监控 (27个币种)
   - 每30分钟采集一次成交额数据
   - 根据阈值分级: V1 / V2 / NONE
   - 显示当前成交额和等级

2. 等级定义
   V1 级别: 成交额 ≥ V1阈值
   - 表示成交额非常活跃
   - 卡片显示绿色背景
   
   V2 级别: V2阈值 ≤ 成交额 < V1阈值
   - 表示成交额较活跃
   - 卡片显示橙色背景
   
   NONE 级别: 成交额 < V2阈值
   - 表示成交额较低
   - 卡片显示灰色背景

3. 阈值配置
   每个币种有独立的V1和V2阈值
   示例:
   - BTC: V1 = 200,000, V2 = 100,000
   - ETH: V1 = 1,300,000, V2 = 500,000
   - SOL: V1 = 351,620, V2 = 246,380
   等

4. 统计信息
   - 总币种数: 27
   - V1级别数量: 9
   - V2级别数量: 1
   - NONE级别数量: 17

5. 自动更新
   - 页面每30秒自动刷新
   - 手动刷新按钮
   - 显示最后更新时间
