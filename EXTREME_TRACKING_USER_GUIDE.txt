## 🎯 系统功能

自动监控市场极值事件，在极值出现时：
1. 记录27个币种的完整快照（价格、涨跌幅、成交量等）
2. 追踪未来1小时、3小时、6小时、12小时、24小时的价格变化
3. 提供完整的历史数据供分析和决策

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## 🚨 5种极值触发条件

1️⃣  **逃顶信号2h极值**
    条件: 每日2h逃顶信号数的最大值 > 50
    说明: 短期内逃顶信号激增

2️⃣  **27币涨跌幅上涨极值**
    条件: 27个币种涨跌幅总和 > 100%
    说明: 市场整体大幅上涨

3️⃣  **27币涨跌幅下跌极值**
    条件: 27个币种涨跌幅总和 < -80%
    说明: 市场整体大幅下跌

4️⃣  **逃顶信号24h极值**
    条件: 48小时窗口内24h信号最大值 > 200
    说明: 持续性逃顶信号

5️⃣  **1小时爆仓金额极值** 🆕
    条件: 1小时爆仓金额 > 3000万美元
    说明: 市场出现大规模爆仓

⏰ 冷却期: 每种极值触发后4小时内不再重复触发

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## 📸 快照包含什么？

每个快照记录以下信息：

✅ **触发信息**
   - 触发时间
   - 触发类型（可能同时触发多种）
   - 触发值

✅ **27个币的数据**
   - 每个币的价格
   - 涨跌幅（金额和百分比）
   - 24小时成交量
   - 市值

✅ **逃顶信号数据**
   - 2小时信号数量
   - 24小时信号数量
   - 是否处于极值状态

✅ **爆仓数据** 🆕
   - 1小时爆仓金额
   - 24小时爆仓金额
   - 恐慌清洗指数

✅ **未来价格追踪**
   - 1小时后的价格和变化
   - 3小时后的价格和变化
   - 6小时后的价格和变化
   - 12小时后的价格和变化
   - 24小时后的价格和变化

## 💡 如何使用？

### 查看最近的极值事件
```bash
curl "http://localhost:5000/api/extreme-tracking/snapshots?limit=10"
```

### 查看某个极值事件的详细追踪
```bash
curl "http://localhost:5000/api/extreme-tracking/snapshot/EXT_1737213123"
```

### 查看统计信息
```bash
curl "http://localhost:5000/api/extreme-tracking/stats"
```

### 只看活跃的追踪（还未完成24小时追踪的）
```bash
curl "http://localhost:5000/api/extreme-tracking/snapshots?status=active"
```

### 只看已完成的追踪（已经完成24小时追踪的）
```bash
curl "http://localhost:5000/api/extreme-tracking/snapshots?status=completed"
```

## 📊 如何分析数据？

### 1. 识别极值模式
查看哪种类型的极值最常出现，什么时候出现

### 2. 观察价格变化规律
- 极值后1小时内价格通常如何变化？
- 极值后24小时内价格走势如何？
- 不同类型的极值，价格反应有何不同？

### 3. 评估极值可靠性
- 某种极值出现后，价格变化是否一致？
- 哪种极值对价格影响最大？
- 极值和价格变化的相关性如何？

### 4. 制定交易策略
- 在极值出现时应该如何操作？
- 根据历史数据预判后续走势
- 设置止损止盈位置

## 🔍 实际应用示例

### 场景1: 市场突然暴跌
```
极值触发: 27币涨跌幅下跌极值（总和 < -80%）
快照时间: 2026-01-18 15:30

可以立即查看:
1. 哪些币跌幅最大？
2. 历史上这种情况后价格如何变化？
3. 是否适合抄底？

1小时后:
- 价格是否反弹？
- 反弹幅度多少？

24小时后:
- 价格走势如何？
- 是否符合预期？
```

### 场景2: 大规模爆仓
```
极值触发: 1小时爆仓金额 > 3000万美元
快照时间: 2026-01-18 20:45

可以分析:
1. 爆仓时各币价格状态
2. 爆仓后价格走势
3. 是否引发连锁反应

追踪观察:
- 短期（1-3小时）价格如何波动
- 中期（6-12小时）是否企稳
- 长期（24小时）价格恢复情况
```

## ❓ 常见问题

**Q: 系统多久检查一次？**
A: 每10分钟检查一次极值条件

**Q: 冷却期是什么意思？**
A: 同一种极值触发后，4小时内不再重复触发，避免重复记录

**Q: 可以同时触发多种极值吗？**
A: 可以！不同类型的极值可以同时触发

**Q: 追踪什么时候完成？**
A: 当5个时间点（1h、3h、6h、12h、24h）都记录后，状态变为completed

**Q: 数据会自动删除吗？**
A: 不会，所有数据永久保存，建议定期归档

**Q: 如何查看历史极值事件？**
A: 使用API接口或直接读取JSONL文件
