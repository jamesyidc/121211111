🔧 技术细节
----------
### 更新脚本功能
`update_support_resistance_jsonl.py` 执行以下操作：

1. 从OKX API获取27个币种的实时价格
2. 计算7天和48小时的支撑压力线
3. 计算当前价格在区间中的位置百分比
4. 保存到 support_resistance_levels.jsonl
5. 记录 record_time_beijing 字段

### 自动更新器逻辑
```python
while True:
    run_update_script()  # 运行更新脚本
    time.sleep(300)      # 等待5分钟
```

### 为什么选择5分钟？
- ⚖️ 平衡：实时性 vs API请求频率
- 🔥 热度：支撑压力线不需要秒级更新
- 💰 成本：避免过度请求OKX API
- 🎯 效果：5分钟延迟对用户影响很小
