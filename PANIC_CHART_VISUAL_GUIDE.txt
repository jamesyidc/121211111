四、如果看不到红色图钉，请按顺序尝试:
----------------------------------------------------------------------------------------

方法1: 强制刷新 (最常用)
  ⌨️  Windows/Linux: Ctrl + Shift + R
  ⌨️  Mac: Cmd + Shift + R
  
  操作步骤:
  1. 在Panic页面按住 Ctrl + Shift 键
  2. 同时按 R 键
  3. 等待页面完全重新加载
  4. 查看图表是否出现红色图钉

方法2: 开发者工具 + 禁用缓存
  1. 按 F12 打开开发者工具
  2. 点击 "Network" (网络) 标签
  3. 勾选 "Disable cache" (禁用缓存)
  4. 按 F5 刷新页面
  5. 查看 Console 标签，确认看到 "📊 图表数据"

方法3: 隐身模式测试 (最可靠)
  ⌨️  Chrome: Ctrl + Shift + N
  ⌨️  Firefox: Ctrl + Shift + P
  
  操作步骤:
  1. 打开隐身/隐私窗口
  2. 复制链接: https://5000-i4rq388xy9v1hw2uaz7ln-8f57ffe2.sandbox.novita.ai/panic
  3. 在隐身窗口中打开链接
  4. 这样可以完全避免缓存影响

方法4: 手动清除缓存
  Chrome:
  1. 按 Ctrl + Shift + Delete
  2. 选择 "缓存的图片和文件"
  3. 时间范围选择 "过去1小时"
  4. 点击 "清除数据"
  5. 刷新Panic页面

八、故障排除
----------------------------------------------------------------------------------------

问题1: 刷新后仍然看不到红色图钉
  检查:
  - 打开 F12 → Console，查看是否有JavaScript错误
  - 确认看到 "📊 图表数据" 输出
  - 确认页面标题显示 "v2.2"
  
  解决:
  - 使用隐身模式测试（方法3）
  - 如问题持续，可能是CDN问题，检查ECharts是否加载成功

问题2: 图表显示空白
  检查:
  - Console中是否有 "加载成功: X条记录"
  - dataPoints 是否大于 0
  
  解决:
  - 检查API: curl http://localhost:5000/api/panic/hour1-curve?hours=1
  - 确认返回数据不为空

问题3: 图钉位置不对
  检查:
  - Console中的 maxIndex 和 max 值
  - 图钉应该在 maxIndex 位置
  
  解决:
  - 这是正常的，图钉位置就是24小时内的最大值位置
  - 最大值位置会随数据更新而变化

问题4: Telegram不发送通知
  检查:
  - configs/telegram_config.json 是否存在
  - bot_token 和 chat_id 是否正确
  - pm2 list 中 liquidation-alert-monitor 是否在线
  
  解决:
  - 测试: python3 source_code/liquidation_alert_monitor.py
  - 查看日志: pm2 logs liquidation-alert-monitor
