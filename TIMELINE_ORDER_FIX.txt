🔍 问题发现
----------
用户反馈：图表时间顺序混乱，应该是**早的在左边，晚的在右边**

❌ 原问题：
- API返回的 history_data 是倒序的（最新在前）
- 前端直接使用倒序数据绘图
- 导致图表显示：右边是早期数据，左边是最新数据
- 时间轴反了！

✅ 解决方案
----------
### 核心修复
在前端加载数据后，将 `result.history_data` 反转为正序：

```javascript
// ⚠️ API返回的数据是倒序的（最新在前），需要反转为正序（最早在前）
const historyDataReversed = result.history_data.slice().reverse();
```

### 全部修改点（5处）
1. ✅ 时间轴数组构建：`historyDataReversed.map()`
2. ✅ 24h/2h信号数组：`historyDataReversed.map()`
3. ✅ 每日2h最高点计算：`historyDataReversed.forEach()`
4. ✅ 48小时峰值计算：遍历 `historyDataReversed`
5. ✅ 空单盈利/亏损标记：`historyDataReversed.forEach()`
6. ✅ 27币数据对齐：`historyDataReversed.forEach()`

🎯 技术细节
----------
### 为什么要反转？
API返回的 `history_data` 格式：
```json
[
  {"stat_time": "2026-01-18 00:13:00", ...},  // 最新
  {"stat_time": "2026-01-18 00:12:00", ...},
  ...
  {"stat_time": "2026-01-03 00:00:48", ...}   // 最早
]
```

ECharts需要的数据格式（X轴从左到右）：
```json
[
  {"stat_time": "2026-01-03 00:00:48", ...},  // 最早（左）
  {"stat_time": "2026-01-03 00:01:55", ...},
  ...
  {"stat_time": "2026-01-18 00:13:00", ...}   // 最新（右）
]
```

### 反转方法
```javascript
const historyDataReversed = result.history_data.slice().reverse();
```
- `slice()`: 创建副本，避免修改原数组
- `reverse()`: 反转数组顺序
