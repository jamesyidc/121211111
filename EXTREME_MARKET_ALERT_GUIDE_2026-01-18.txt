【🔌 API接口使用】
═══════════════════════════════════════════════════════════════════════════════

1. 获取预警统计:
   curl "http://localhost:5000/api/extreme-market-alerts/stats"
   
   返回示例:
   {
     "success": true,
     "stats": {
       "total_count": 17,
       "extreme_high_count": 5,
       "extreme_low_count": 12,
       "latest_alert": {
         "alert_time": "2026-01-18 15:30:00",
         "alert_type": "extreme_high",
         "alert_type_name": "极端上涨",
         "total_change": 105.25
       }
     }
   }

2. 获取预警历史:
   curl "http://localhost:5000/api/extreme-market-alerts/latest?limit=10"
   
   返回最近10条预警记录，包含:
   - alert_time: 预警时间
   - alert_type: 预警类型
   - total_change: 总涨跌幅
   - coin_count: 币种数量
   - details: 详细数据（各币种涨跌幅）
